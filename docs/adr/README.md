# Architecture Decision Records

ADRs record context/options/decision/consequences/security/approval evidence. **CONFIRMED** means explicitly fixed by the Product Owner master specification, not implemented/tested. **PROPOSED** means a detailed recommendation awaiting review. Superseded choices are explained in the affected ADR, not left as competing current defaults.

1. [0001 — On-premise modular baseline](0001-on-premise-modular-baseline.md)
2. [0002 — Managed versus Indexed repositories](0002-managed-and-indexed-repositories.md)
3. [0003 — PostgreSQL search and local processing](0003-postgresql-search-local-processing.md)
4. [0004 — NAS gateway and operation consistency](0004-nas-gateway-operation-consistency.md)

The [consolidated register](../DECISION_REGISTER.md) is the only source of unresolved decisions. Dependency versions and technical qualification evidence will be recorded when selected/tested under implementation approval.
